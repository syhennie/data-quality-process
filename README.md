## Проект по генерации синтетических текстовых табличных данных для тестирования в ETL-процессах.

Данный проект реализован в рамках выпускной квалификационной работы по теме  "Разработка обеспечения качества данных". Задача была поставлена АО "Т-Банк".

### Цель
**Создать пайплайн генерации синтетических данных** для тестирования и разработки ETL-пайплайнов, снижая риск утечки конфиденциальных данных и обеспечивая соблюдение ФЗ-152 "О персональных данных". **Синтетические** данные **должны быть близки** к исходным векторным представлениям текстов **по распределению**.

### Входные данные
Датасет, содержащий чувствительную информацию.

### Описание этапов генерации
1. Поля данных конвертируются в высокоразмерные эмбеддинги с помощью предобученной модели ```all-MiniLM-L6-v2```.
2. Эмбеддинги обучают энкодер ```вариационного автоэнкодера (VAE)``` с гиперпараметром ```β```. β контролирует вклад регуляризации латентного пространства VAE.
3. Из стандартного нормально распределения семплируется латентный вектор. С помощью декодера VAE восстанавливается синтетический эмбеддинг, формируя синтетический датасет.
4. Для каждой колонки каждого датасета вычисляется конечное множество статистических метрик, обеспечивающих контроль качества генерации.
5. Синтетические эмбеддинги проецируются в пространство ```t5-small``` через обучаемый проектор и декодируются в текст методом Beam Search.

### Критерий отклонения
Характеристиками распределений эмбеддингов являются статистические моменты, являющиеся векторами высокой размерности. В качестве критерия отклонения выбрана MAE.
Дополнительно, для комплексной оценки качества расчитывается усредненное расстояние Вассерштейна по случайным одномерным проекциям (SWD), косинусная схожесть центроидов и попарное разнообразие.

### Выходные данные
Датасет, не содержащий чувствительной информации, схожий по распределению с изначальным и пригодный для использования в ETL-процессах.

### Результаты
MAE по всем моментам $\le$ 0.1, близость распределений по Вассерштейну $\ge$ 97%. Результаты доказали пригодность для тестирования ETL. Получена благодарность от АО "Т-Банк".

Ноутбук с подробными результатами по метриками и примерами синтетических текстов лежит в orlov-alexander/res-notebook.ipynb

### Структура модуля
synthetic_vae/

├── pipeline.py     — оркестратор SyntheticEmbeddingPipeline

├── vectorizer.py   — векторизация текста (all-MiniLM-L6-v2)

├── stats.py        — статистики эмбеддингов, нормализация

├── model.py        — архитектура VAE, LogCosh loss, β-расписания

├── trainer.py      — цикл обучения, денормализация генераций

├── validation.py   — метрики качества: MAE, SWD, косинусная схожесть

└── decoder.py      — T5-декодер (EmbeddingToTextDecoder)
