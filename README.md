# data-quality-process

## v0

Наивное кодирование записей по всей записи целиком. Была возможность генерировать только свойства записи, но не декодировать по свойствам запись в исходном виде. Генерация с помощью приближения нормального распределения и последующей генерации случайной выборки.

## v1

Кодирование каждого токена (слова) отдельно, появилась возможность декодировать записи в оригинальный вид (вектор -> текст).
Генерация осталось такой же как и в v0.

## v2

Кодирование каждого токена (слова) отдельно, как в v1.
Генерация реализована с помощью CTGAN.
